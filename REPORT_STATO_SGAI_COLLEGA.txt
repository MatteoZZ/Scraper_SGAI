4. VINCOLO CENTRALE (AKAMAI)
----------------------------
Il portale non offre API pubbliche usabili in headless.
Akamai valuta soprattutto:
  1) IP di uscita
  2) Ritmo (ricerche, click ">", download)
  3) Sessione browser / fingerprint

Regola operativa: 1 worker serio = 1 exit IP dedicato.

Una VPN consumer aiuta UN tunnel; NON moltiplica gli IP sullo stesso PC.
Per il parallelo servono proxy sticky (o più macchine/reti).
